# MySQL 数据库安装与导入指南

## 📋 前置要求

- ✅ MySQL 已安装（MySQL 5.7+ 或 MySQL 8.0+）
- ✅ 知道 MySQL root 用户密码（默认配置为：`123456`）

---

## 🚀 方法一：命令行方式（推荐）

### 步骤1：启动 MySQL 服务

#### Windows 系统：
```powershell
# 方法1：使用服务管理器
net start MySQL

# 方法2：使用服务名称（如果服务名不同）
net start MySQL80  # MySQL 8.0
# 或
net start MySQL57  # MySQL 5.7

# 方法3：在服务管理器中启动
# Win + R -> services.msc -> 找到 MySQL 服务 -> 启动
```

#### Linux/Mac 系统：
```bash
# Ubuntu/Debian
sudo systemctl start mysql
# 或
sudo service mysql start

# Mac
brew services start mysql
# 或
sudo /usr/local/mysql/support-files/mysql.server start
```

### 步骤2：验证 MySQL 服务状态

```bash
# Windows PowerShell
Get-Service MySQL*

# Linux/Mac
sudo systemctl status mysql
# 或
ps aux | grep mysql
```

### 步骤3：登录 MySQL

```bash
# 在项目根目录（D:\kksyc1\WxMinPro）打开命令行
mysql -u root -p

# 输入密码：123456（或你的实际密码）
```

### 步骤4：创建数据库

在 MySQL 命令行中执行：

```sql
CREATE DATABASE IF NOT EXISTS `audio` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 步骤5：导入数据库脚本

**方法A：在 MySQL 命令行中执行**

```sql
USE `audio`;
source backend/database/zy.sql;
```

**方法B：使用命令行直接导入（推荐）**

退出 MySQL（输入 `exit`），然后在项目根目录执行：

```bash
# Windows PowerShell
mysql -u root -p123456 audio < backend\database\zy.sql

# Linux/Mac
mysql -u root -p123456 audio < backend/database/zy.sql
```

> ⚠️ 注意：`-p` 和密码之间没有空格。如果不想在命令行显示密码，可以只写 `-p`，然后手动输入密码。

## ✅ 验证安装

### 1. 检查表是否创建成功

```sql
USE audio;
SHOW TABLES;
```

**应该看到4个表：**
- `users` - 用户表
- `denoisetable` - 音频降噪历史记录表
- `sepaudiotable` - 音频分离历史记录表
- `chattable` - 聊天记录表

### 2. 检查表结构

```sql
DESCRIBE users;
DESCRIBE denoisetable;
DESCRIBE sepaudiotable;
DESCRIBE chattable;
```

### 3. 检查默认管理员账户

```sql
SELECT * FROM users WHERE Phone = '13685153598';
```

**应该看到：**
- 手机号：`13685153598`
- 用户名：`SM`
- 密码：`123456`
- 用户类型：`1`（管理员）
- 配额：`999999`（分离和降噪）

## ⚙️ 配置后端连接

确保 `backend/db_config.py` 中的配置正确：

```python
DB_CONFIG = {
    'host': 'localhost',
    'port': 3306,
    'user': 'root',
    'password': '123456',  # ⚠️ 修改为你的实际密码
    'database': 'audio',   # 确保与创建的数据库名一致
    'charset': 'utf8mb4'
}
```

### 测试数据库连接

```bash
cd backend
python db_config.py
```

**如果看到：**
```
✅ 数据库连接成功！
```

说明配置正确！

## 🔧 常见问题排查

### 问题1：MySQL 服务无法启动

**Windows：**
```powershell
# 检查服务状态
Get-Service MySQL*

# 查看错误日志
# 日志位置通常在：C:\ProgramData\MySQL\MySQL Server 8.0\Data\*.err
```

**解决方案：**
- 检查端口 3306 是否被占用
- 检查 MySQL 配置文件（my.ini 或 my.cnf）
- 重新安装 MySQL

### 问题2：Access denied for user 'root'@'localhost'

**原因：** 密码错误或用户权限问题

**解决方案：**
```sql
-- 重置 root 密码（需要管理员权限）
ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
```

### 问题3：No database selected

**原因：** 没有先创建或选择数据库

**解决方案：**
```sql
-- 先创建数据库
CREATE DATABASE IF NOT EXISTS `audio` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

-- 再选择数据库
USE `audio`;

-- 然后执行脚本
source backend/database/zy.sql;
```

### 问题4：字符集错误

**检查数据库字符集：**
```sql
SHOW CREATE DATABASE audio;
```

**如果不对，重新创建：**
```sql
DROP DATABASE audio;
CREATE DATABASE audio DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 问题5：表已存在错误

**如果表已存在，脚本会自动删除并重建。** 如果仍有问题：

```sql
USE audio;
DROP TABLE IF EXISTS users;
DROP TABLE IF EXISTS denoisetable;
DROP TABLE IF EXISTS sepaudiotable;
DROP TABLE IF EXISTS chattable;

-- 然后重新执行 zy.sql
```
