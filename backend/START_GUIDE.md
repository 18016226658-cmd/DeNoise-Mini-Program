# 后端服务器启动指南

## 问题诊断

如果运行 `start.py` 后程序立即退出，可能是以下原因：
1. `app.run()` 调用时出现异常但被静默捕获
2. 程序正常启动但输出被缓冲
3. 端口已被占用

## 推荐启动方式

### 方法1：使用 run_server.py（最可靠）

```bash
cd D:\kksyc1\WxMinPro\backend
python -u run_server.py
```

这个脚本包含完整的异常处理和调试信息。

### 方法2：使用修复后的 start.py

```bash
cd D:\kksyc1\WxMinPro\backend
python -u start.py
```

### 方法3：使用 run.py

```bash
cd D:\kksyc1\WxMinPro\backend
python -u run.py
```

## 验证服务器是否运行

### 检查端口

```bash
netstat -ano | findstr :5000
```

如果看到 `LISTENING` 状态，说明服务器正在运行。

### 测试API

在浏览器中访问：
```
http://127.0.0.1:5000/api/DeNoiseAudio
```

如果返回 405 Method Not Allowed（而不是 404 或连接失败），说明服务器正常运行。

## 成功启动的标志


## 如果程序立即退出

1. **检查是否有错误信息**：查看控制台输出的最后几行
2. **检查端口是否被占用**：`netstat -ano | findstr :5000`
3. **尝试使用 run_server.py**：它包含更详细的错误处理
4. **检查 Python 版本**：`python --version`（建议 3.8-3.11）

## 常见问题

### 1. 端口已被占用

**解决方法：**
- 关闭占用端口的进程
- 或修改启动脚本中的端口号（如改为 5001）

### 2. 程序启动后立即退出

**解决方法：**
- 使用 `python -u` 参数确保输出不被缓冲
- 使用 `run_server.py` 查看详细错误信息
- 检查是否有异常被静默捕获

### 3. 前端无法连接

**解决方法：**
- 确认服务器正在运行（检查端口）
- 检查防火墙设置
- 确认前端配置的地址是 `http://127.0.0.1:5000`
