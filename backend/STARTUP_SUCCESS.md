# 后端启动成功指南

## 启动状态检查

如果看到以下输出，说明后端已成功启动：

```
============================================================
🚀 音频降噪系统后端服务启动中...
============================================================
⚠️  提示：Java调用功能不可用（jpype1未安装）
   如需使用Java调用功能，请运行: pip install jpype1
============================================================
📡 服务地址: http://127.0.0.1:5000
============================================================
 * Running on http://0.0.0.0:5000
 * Debug mode: on
```

## jieba 警告说明

如果看到以下警告，**可以忽略**，不影响功能：

```
UserWarning: pkg_resources is deprecated as an API
```

这是 `jieba` 库的依赖警告，不影响程序运行。

## 验证服务是否启动

### 方法1：查看控制台输出
- 看到 `Running on http://0.0.0.0:5000` 表示启动成功
- 程序会一直运行，不要关闭终端

### 方法2：测试API
打开浏览器访问：
- http://127.0.0.1:5000/api/Login
- 应该看到响应（可能是错误，但说明服务在运行）

### 方法3：使用curl测试
```bash
curl http://127.0.0.1:5000/api/Login
```

## 常见问题

### Q1: 只看到警告，没有看到启动信息？
A: 程序可能正在启动中，等待几秒钟。如果超过10秒还没有输出，检查是否有错误。

### Q2: 端口被占用？
A: 如果5000端口被占用，会看到错误。可以：
- 关闭占用端口的程序
- 或修改 `app.py` 中的端口号

### Q3: 数据库连接失败？
A: 检查 `backend/db_config.py` 中的数据库配置是否正确。
