# 快速启动指南

## 问题诊断

前端报错 `ERR_CONNECTION_REFUSED`，说明后端服务器没有运行。

## 启动后端服务器

### 方法1：使用最简单的启动脚本（推荐）

```bash
cd D:\kksyc1\WxMinPro\backend
python -u start.py
```

### 方法2：使用修复后的 run.py

```bash
cd D:\kksyc1\WxMinPro\backend
python -u run.py
```

### 方法3：直接运行 app.py

```bash
cd D:\kksyc1\WxMinPro\backend
python -u app.py
```

## 验证服务器是否运行

### 检查端口

```bash
netstat -ano | findstr :5000
```

如果看到 `LISTENING` 状态，说明服务器正在运行。

### 测试API

在浏览器中访问：
```
http://127.0.0.1:5000/api/DeNoiseAudio
```

如果返回 405 Method Not Allowed（而不是 404 或连接失败），说明服务器正常运行。

## 常见问题

### 1. 端口已被占用

如果端口5000已被占用：
- 关闭占用端口的进程
- 或修改启动脚本中的端口号

### 2. 服务器启动后立即退出

如果服务器启动后立即退出（崩溃）：
- 检查是否有错误信息
- 尝试使用 `start.py`（最简单的启动脚本）
- 检查是否有多个 Python 进程在运行

### 3. 前端仍然无法连接

如果服务器运行但前端仍然无法连接：
- 检查防火墙设置
- 确认前端配置的地址是 `http://127.0.0.1:5000`
- 检查微信开发者工具的网络设置

## 成功启动的标志

看到以下输出说明服务器成功启动：

```
============================================================
音频降噪系统后端服务
服务地址: http://127.0.0.1:5000
============================================================
 * Running on http://0.0.0.0:5000
 * Debug mode: on
```

## 如果仍然无法启动

1. 检查 Python 版本：`python --version`（建议 3.8-3.11）
2. 检查依赖是否安装：`pip list`
3. 查看详细错误信息
4. 尝试使用系统 Python 而不是 venv
