# 后端服务器启动指南

## 问题诊断

从错误日志看，前端调用后端API时出现：
- `/api/getAudioInfo` 返回 500 错误
- `/api/DeNoiseAudio` 返回 404 错误

这说明后端服务器可能没有正确启动或路由没有正确注册。

## 启动步骤

### 方法1：使用 run.py（推荐）

```bash
cd backend
python -u run.py
```

**注意：** 使用 `-u` 参数确保输出不被缓冲，可以看到实时日志。

### 方法2：直接运行 app.py

```bash
cd backend
python -u app.py
```

## 验证服务器是否运行

### 检查端口是否被占用

```bash
netstat -ano | findstr :5000
```

如果看到 `LISTENING` 状态，说明端口已被占用。

### 测试API是否可用

在浏览器中访问：
```
http://127.0.0.1:5000/api/DeNoiseAudio
```

如果返回 405 Method Not Allowed（而不是 404），说明路由已注册，只是方法不对（需要POST）。

## 常见问题

### 1. 端口已被占用

如果端口5000已被占用，可以：
- 关闭占用端口的进程
- 或者修改 `run.py` 中的端口号

### 2. 路由返回404

可能原因：
- 后端服务器没有启动
- 路由没有正确注册
- 有多个后端实例在运行，导致冲突

**解决方法：**
1. 确保只有一个后端实例在运行
2. 重启后端服务器
3. 检查 `app.py` 中的路由定义

### 3. 路由返回500

可能原因：
- 代码中有错误
- 依赖库缺失
- 文件路径不存在

**解决方法：**
1. 查看后端控制台的错误信息
2. 检查相关文件路径是否存在
3. 确保所有依赖库已安装

## 调试技巧

1. **查看实时日志**：使用 `python -u run.py` 可以看到实时输出
2. **检查路由注册**：运行 `python -c "from app import app; print(list(app.url_map.iter_rules()))"`
3. **测试单个路由**：使用 Postman 或 curl 测试API
