# 依赖安装检查

如果遇到 `ModuleNotFoundError`，请安装所有依赖：

```bash
cd backend
pip install -r requirements.txt
```

## 常见缺失的依赖

- `pydub` - 音频处理
- `mutagen` - 音频元数据读取
- `scipy` - 科学计算（音频降噪需要）
- `jieba` - 中文分词
- `snownlp` - 中文情感分析
- `matplotlib` - 图表绘制
- `pandas` - 数据处理

## 快速安装

```bash
# 在 backend 目录下
pip install -r requirements.txt
```
