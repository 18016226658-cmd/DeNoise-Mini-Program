# 基于微信小程序的大整数分解系统设计与实现

## 摘要

本文设计并实现了一个基于微信小程序的大整数分解系统，采用前后端分离架构。前端使用微信小程序框架提供用户界面，后端使用 Python Flask 框架实现大整数分解算法和数据库管理。系统采用 Pollard's Rho 算法和 Miller-Rabin 素性测试实现大整数分解，支持最多 200 位整数的分解计算。系统实现了用户管理、历史记录、可视化分析等功能，并通过 MySQL 数据库进行数据持久化存储。

**关键词**：大整数分解；微信小程序；Python Flask；Pollard's Rho；Miller-Rabin

## 1. 引言

### 1.1 研究背景

大整数分解是数论和密码学中的重要问题，在 RSA 加密算法、密码破解等领域有广泛应用。随着计算能力的提升，传统的小规模整数分解方法已无法满足需求，需要设计高效的算法和系统来处理大整数分解问题。

微信小程序作为一种轻量级应用平台，具有无需安装、即用即走的特点，为用户提供了便捷的使用体验。将大整数分解功能集成到微信小程序中，可以方便用户随时进行大整数分解计算。

### 1.2 研究意义

本系统的研究意义主要体现在以下几个方面：

1. **算法实现**：实现了 Pollard's Rho 算法和 Miller-Rabin 素性测试，为大规模整数分解提供了高效的解决方案。
2. **系统架构**：采用前后端分离架构，将计算密集型任务放在后端处理，前端专注于用户交互，提高了系统的可维护性和扩展性。
3. **用户体验**：通过微信小程序提供友好的用户界面，用户可以随时随地进行大整数分解计算。
4. **数据管理**：实现了完整的用户管理和历史记录功能，支持数据分析和可视化展示。

### 1.3 论文结构

本文共分为六个章节：

## 2. 系统需求分析

### 2.1 功能需求

#### 2.1.1 用户管理功能

- **用户注册**：新用户可以通过注册功能创建账户，需要提供用户名、密码、性别、出生日期、职业等信息。
- **用户登录**：已注册用户可以通过用户名和密码登录系统。
- **用户权限管理**：系统支持四级用户权限：普通用户、VIP 用户、SVIP 用户和管理员。不同权限对应不同的最大分解位数限制。

#### 2.1.2 大整数分解功能

- **输入验证**：系统对用户输入进行严格验证，只允许输入 0-9 数字，最大支持 200 位整数。
- **分解计算**：使用 Pollard's Rho 算法和 Miller-Rabin 素性测试进行大整数分解。
- **结果展示**：展示分解结果，包括所有因子、分解式、计算耗时、数字类型和分解程度等信息。

#### 2.1.3 历史记录功能

- **自动保存**：每次分解完成后自动保存到历史记录。
- **记录查询**：用户可以查看自己的历史记录，管理员可以查看所有用户的历史记录。
- **记录统计**：提供历史记录统计信息，包括总记录数和完全分解记录数。

#### 2.1.4 管理员功能

- **用户管理**：管理员可以查看所有用户列表，按等级筛选用户，修改用户等级。
- **可视化分析**：提供多种可视化图表，包括职业使用时间分布、用户偏好分析、使用统计等。

### 2.2 非功能需求

#### 2.2.1 性能需求

- **响应时间**：20 位数字分解时间 < 5 秒，50 位数字分解时间 < 30 秒，100 位数字分解时间 < 120 秒。
- **并发处理**：系统应支持多用户同时使用，后端采用异步处理机制。

#### 2.2.2 安全需求

- **用户认证**：所有 API 接口需要用户登录认证，管理员功能需要额外权限验证。
- **数据安全**：用户密码应进行加密存储（当前版本为演示版本，使用明文存储）。

#### 2.2.3 可用性需求

- **界面友好**：提供简洁美观的用户界面，操作流程清晰。
- **错误处理**：提供完善的错误提示和异常处理机制。

### 3.4 前后端通信设计

#### 3.4.1 通信协议

系统采用 **HTTP/JSON** 协议进行前后端通信：

- **协议**：HTTP/HTTPS
- **数据格式**：JSON
- **请求方法**：GET、POST、PUT、DELETE
- **认证方式**：Token 认证（当前使用用户名作为 Token，生产环境应使用 JWT）

#### 3.4.2 前端请求封装

前端使用统一的 `requestApi()` 函数封装所有后端请求，位于 `utils/common.js`：

```javascript
function requestApi(options = {}) {
  const { url, method = 'GET', data = {}, success, fail } = options;
  
  wx.request({
    url: BASE_URL + url,  // BASE_URL = 'http://127.0.0.1:5000'
    method,
    data,
    header: {
      'Content-Type': 'application/json',
      'Authorization': getAuthToken()  // 自动添加认证 Token
    },
    success: (res) => {
      // 统一处理 401 未授权
      if (res.statusCode === 401) {
        wx.reLaunch({ url: '/pages/login/login' });
        return;
      }
      if (typeof success === 'function') {
        success(res);
      }
    },
    fail: (err) => {
      showError('网络请求失败，请检查网络或稍后重试');
      if (typeof fail === 'function') {
        fail(err);
      }
    }
  });
}
```

**关键特性**：
1. **自动拼接 URL**：`BASE_URL + url`
2. **自动添加认证头**：从本地存储获取 Token 并添加到 `Authorization` 头
3. **统一错误处理**：401 错误自动跳转登录页
4. **统一加载提示**：自动显示/隐藏 loading

#### 3.4.4 认证机制

**当前实现**（简单版本）：
- Token = 用户名
- Token 存储在请求头的 `Authorization` 字段
- 后端通过 `@login_required` 装饰器验证 Token

**登录验证装饰器**（`backend/api/auth.py`）：

```python
def login_required(f):
    """登录验证装饰器"""
    @wraps(f)
    def decorated_function(*args, **kwargs):
        token = request.headers.get('Authorization')
        if not token:
            return jsonify({'success': False, 'message': '未登录'}), 401
        
        user = User.query.filter_by(username=token).first()
        if not user:
            return jsonify({'success': False, 'message': '无效的 token'}), 401
        
        request.current_user = user  # 注入用户对象
        return f(*args, **kwargs)
    return decorated_function
```

**使用方式**：
```python
@factorize_bp.route('/factorize', methods=['POST'])
@login_required  # 使用装饰器
def factorize_number():
    user = request.current_user  # 装饰器已注入用户对象
    # ...
```

**用户信息全局管理** (`app.js`)

系统使用全局变量机制管理用户信息，确保所有页面都能访问到最新的用户等级和分解位数限制：

```javascript
// app.js
App({
  globalData: {
    userInfo: null,      // 用户信息（包含等级、maxDigits等）
    history: [],         // 历史记录
    isLoggedIn: false   // 登录状态
  },

  // 获取用户信息
  getUserInfo() {
    return this.globalData.userInfo || wx.getStorageSync('currentUser', null);
  },

  // 更新用户信息（统一方法，确保全局变量和本地存储同步）
  updateUserInfo(userInfo) {
    try {
      // 统一字段名，确保兼容性（后端返回max_digits，前端可能使用maxDigits）
      const normalizedUserInfo = {
        ...userInfo,
        // 确保同时有max_digits和maxDigits
        max_digits: userInfo.max_digits || userInfo.maxDigits || 50,
        maxDigits: userInfo.max_digits || userInfo.maxDigits || 50,
        // 确保同时有level_name和levelName
        level_name: userInfo.level_name || userInfo.levelName || '普通用户',
        levelName: userInfo.level_name || userInfo.levelName || '普通用户'
      };
      
      // 更新全局变量（所有页面都能访问）
      this.globalData.userInfo = normalizedUserInfo;
      this.globalData.isLoggedIn = true;
      
      // 更新本地存储
      wx.setStorageSync('currentUser', normalizedUserInfo);
      
      console.log('用户信息已更新到全局变量:', {
        username: normalizedUserInfo.username,
        level: normalizedUserInfo.level,
        maxDigits: normalizedUserInfo.maxDigits
      });
    } catch (e) {
      console.error('更新用户信息失败:', e);
    }
  }
});
```

#### 4.1.3 工具函数实现

**API 请求封装** (`utils/common.js`)

前端通过统一的 `requestApi()` 函数与后端通信，该函数封装了微信小程序的 `wx.request()` API：

```javascript
// 后端地址配置
const BASE_URL = 'http://127.0.0.1:5000';  // 开发阶段
// const BASE_URL = 'http://192.168.1.100:5000';  // 真机调试

// 获取认证 Token
function getAuthToken() {
  const currentUser = wx.getStorageSync('currentUser');
  return currentUser && currentUser.username ? currentUser.username : '';
}

// 统一请求封装
function requestApi(options = {}) {
  const { url, method = 'GET', data = {}, success, fail, showLoading = true } = options;
  
  if (showLoading) {
    wx.showLoading({ title: '请求中...', mask: true });
  }
  
  wx.request({
    url: BASE_URL + url,  // 拼接完整 URL
    method,
    data,
    header: {
      'Content-Type': 'application/json',
      'Authorization': getAuthToken()  // 自动添加认证头
    },
    success: (res) => {
      if (showLoading) {
        wx.hideLoading();
      }
      
      // 统一处理 401 未授权
      if (res.statusCode === 401) {
        wx.removeStorageSync('currentUser');
        wx.reLaunch({ url: '/pages/login/login' });
        return;
      }
      
      if (typeof success === 'function') {
        success(res);
      }
    },
    fail: (err) => {
      if (showLoading) {
        wx.hideLoading();
```

### 4.2 后端实现

#### 4.2.1 核心算法实现

**Miller-Rabin 素性测试** (`backend/algorithms.py`)

```python
def miller_rabin(n, k=5):
    """Miller-Rabin素性测试"""
    if n == 2 or n == 3:
        return True
    if n < 2 or n % 2 == 0:
        return False
    
    # 将 n-1 写成 d * 2^r 的形式
    d = n - 1
    r = 0
    while d % 2 == 0:
        d = d // 2
        r += 1
    
    # 进行k轮测试
    for i in range(k):
        a = random.randint(2, n - 2)
        x = mod_pow(a, d, n)
        
        if x == 1 or x == n - 1:
            continue
        
        composite = True
        for j in range(r - 1):
            x = (x * x) % n
            if x == n - 1:
                composite = False
                break
        
        if composite:
            return False
    
    return True
```

**Pollard's Rho 算法** (`backend/algorithms.py`)

```python
def pollard_rho(n):
    """Pollard's Rho算法（Brent变体）"""
    if n % 2 == 0:
        return 2
    if miller_rabin(n):
        return None
    
    # 根据数字大小动态调整最大迭代次数
    num_digits = len(str(n))
    if num_digits <= 20:
        max_iterations = 100000
    elif num_digits <= 40:
        max_iterations = 500000
    # ... 更多条件
    
    # 使用随机初始值
    x = random.randint(1, n - 1)
    y = x
    k = 2
    
    for i in range(max_iterations):
        x = (x * x - 1) % n
        d = gcd(abs(y - x), n)
        
        if d > 1 and d < n:
            return d
        
        if i == k:
            y = x
            k = k * 2
    
    return None
```

**分解接口** (`backend/api/factorize.py`)

```python
from flask import Blueprint, request, jsonify
from api.auth import login_required
from algorithms import factorize, validate_input, get_number_type, get_factorization_level
from models import db, History
from datetime import datetime
import json

factorize_bp = Blueprint('factorize', __name__)

@factorize_bp.route('/factorize', methods=['POST'])
@login_required  # 需要登录才能访问
def factorize_number():
    """分解大整数"""
    try:
        # 1. 获取请求数据
        data = request.get_json()
        number_str = data.get('number', '').strip()
        mode = data.get('mode', 'standard')
        
        # 2. 验证输入
        validation = validate_input(number_str)
        if not validation['valid']:
            return jsonify({
                'success': False,
                'message': validation['error']
            }), 400
        
        number = validation['number']
        digit_count = len(number_str)
        
        # 3. 检查用户权限（从装饰器注入的 request.current_user 获取）
        user = request.current_user
        if digit_count > user.max_digits:
            return jsonify({
                'success': False,
                'message': f'超过最大位数限制（{user.max_digits}位）'
            }), 403
        
        # 4. 开始分解
        start_time = datetime.now()
        factors = factorize(number, mode=mode)
        elapsed_time = (datetime.now() - start_time).total_seconds()
        
        # 5. 判断数字类型和分解程度
        number_type = get_number_type(number, factors)
        factorization_level = get_factorization_level(number, factors)
        
        # 6. 生成分解式
        factor_counts = {}
        for f in factors:
            key = str(f)
            factor_counts[key] = factor_counts.get(key, 0) + 1
        
        formula_parts = []
        for factor, count in factor_counts.items():
            if count > 1:
                formula_parts.append(f'{factor}^{count}')
            else:
                formula_parts.append(str(factor))
        formula = ' × '.join(formula_parts)
        
        # 7. 验证每个因子是否为素数
        factors_with_prime = []
        for f in factors:
            from algorithms import miller_rabin
            is_prime = False
            if f > 1:
                is_prime = miller_rabin(f, 3)
            factors_with_prime.append({
                'value': str(f),
                'is_prime': is_prime
            })
        
        # 8. 生成结果
        result = {
            'number': number_str,
            'factors': factors_with_prime,
            'formula': formula,
            'elapsed_time': round(elapsed_time, 3),
            'number_type': number_type['type'],
            'number_type_name': number_type['type_name'],
            'number_type_desc': number_type['description'],
            'factorization_level': factorization_level['level'],
            'factorization_level_name': factorization_level['level_name'],
            'factorization_level_desc': factorization_level['description']
        }
        
        # 9. 保存到历史记录
        history = History(
            user_id=user.id,
            number=number_str,
            factors=json.dumps([str(f) for f in factors]),
            formula=formula,
            number_type=number_type['type'],
            number_type_name=number_type['type_name'],
            factorization_level=factorization_level['level'],
            factorization_level_name=factorization_level['level_name'],
            elapsed_time=elapsed_time,
            digit_count=digit_count
        )
        db.session.add(history)
        db.session.commit()
        
        # 10. 返回结果
        return jsonify({
            'success': True,
            'data': result
        })
    except Exception as e:
        db.session.rollback()
        return jsonify({
            'success': False,
            'message': f'分解失败: {str(e)}'
        }), 500
```

```javascript
const BASE_URL = 'http://127.0.0.1:5000';

function requestApi(options = {}) {
  const { url, method = 'GET', data = {}, success, fail } = options;
  
  wx.request({
    url: BASE_URL + url,
    method,
    data,
    header: {
      'Content-Type': 'application/json',
      'Authorization': getAuthToken()
    },
    success: (res) => {
      if (res.statusCode === 401) {
        wx.reLaunch({ url: '/pages/login/login' });
        return;
      }
      if (typeof success === 'function') {
        success(res);
      }
    },
    fail: (err) => {
      showError('网络请求失败，请检查网络或稍后重试');
      if (typeof fail === 'function') {
        fail(err);
      }
    }
  });
}
```
