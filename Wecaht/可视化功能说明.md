# 可视化分析功能说明

## 一、功能概述

系统为管理员提供了三种可视化分析功能，帮助管理员了解系统使用情况和用户行为：

1. **职业使用时间分布**：分析不同职业在一天24小时内的使用时间分布
2. **用户偏好分析**：分析用户年龄、性别、职业、数字位数、分解类型等偏好
3. **使用统计**：查看系统整体使用情况，包括用户数、使用次数、成功率等

---

## 二、后端实现位置

### 1. 可视化接口

**文件位置**：`backend/api/analysis.py`

所有可视化接口都在此文件中实现：

- `GET /api/analysis/job-usage-time` - 职业使用时间分布
- `GET /api/analysis/user-preferences` - 用户偏好分析
- `GET /api/analysis/usage-statistics` - 使用统计

### 2. 图表生成

后端使用 **Matplotlib** 生成图表：

```python
import matplotlib
matplotlib.use('Agg')  # 使用非交互式后端
import matplotlib.pyplot as plt
import io
import base64

# 生成图表
fig, ax = plt.subplots(figsize=(14, 8))
# ... 绘制图表 ...
plt.tight_layout()

# 保存为 Base64 图片
img_buffer = io.BytesIO()
plt.savefig(img_buffer, format='png', dpi=100)
img_buffer.seek(0)
img_base64 = base64.b64encode(img_buffer.read()).decode('utf-8')
plt.close()

# 返回给前端
return jsonify({
    'success': True,
    'data': {
        'image': f'data:image/png;base64,{img_base64}',
        # ... 其他统计数据 ...
    }
})
```

### 3. 数据来源

所有可视化数据都来自 MySQL 数据库：

- **用户数据**：`users` 表（职业、性别、年龄等）
- **历史记录**：`histories` 表（使用时间、数字位数、分解类型等）

### 3. 前端逻辑

**文件位置**：`pages/admin/admin.js`

```javascript
// 显示职业使用时间分布
showJobUsageTime() {
  this.loadVisualization('职业使用时间分布', '/api/analysis/job-usage-time');
},

// 加载可视化数据
loadVisualization(title, url) {
  this.setData({
    showVizModal: true,
    vizTitle: title,
    vizLoading: true
  });

  requestApi({
    url: url,
    method: 'GET',
    success: (res) => {
      const data = res.data || {};
      if (data.success) {
        const payload = data.data || {};
        
        // 显示图表图片
        if (payload.image) {
          this.setData({
            vizImage: payload.image,
            vizLoading: false
          });
        }
        
        // 显示统计数据
        // ...
      }
    }
  });
}
```

## 六、可视化图表说明

### 1. 职业使用时间分布

**图表类型**：折线图

**内容**：
- X 轴：24小时（00:00 - 23:00）
- Y 轴：使用次数
- 多条折线：每个职业一条线

**统计数据**：
- 各职业的总使用次数

### 2. 用户偏好分析

**图表类型**：多子图（2×3布局）

**包含**：
1. 各职业使用频率（饼图）
2. 性别使用频率（柱状图）
3. 年龄段使用频率（柱状图）
4. 数字位数分布（柱状图）
5. 数字类型分布（饼图）
6. 每日使用趋势（折线图）

**统计数据**：
- 各职业使用次数
- 各性别使用次数
- 各年龄段使用次数
- 各位数范围使用次数

### 3. 使用统计

**图表类型**：多子图（2×2布局）

**包含**：
1. 时间维度使用统计（柱状图）：今日、本周、本月、总计
2. 用户等级分布（饼图）：普通、VIP、SVIP、管理员
3. 分解类型分布（柱状图）：完全分解、部分分解、失败
4. 数字位数分布（折线图）：1-10位、11-20位等

**统计数据**：
- 总用户数
- 总使用次数
- 今日/本周/本月使用次数
- 平均耗时
- 完全分解成功率
- 各等级用户数
- 各分解类型次数

## 七、技术要点

### 1. 后端图表生成

- 使用 Matplotlib 生成图表
- 设置中文字体支持
- 转换为 Base64 编码返回给前端
- 使用非交互式后端（Agg）适合服务器环境

### 2. 前端图片展示

- 使用 `<image>` 组件显示 Base64 图片
- `mode="widthFix"` 保持图片比例
- 弹窗形式展示，用户体验更好

### 3. 数据统计

- 后端从数据库查询并统计
- 前端展示统计数据和图表
- 支持实时数据更新

---

## 八、注意事项

1. **数据要求**：可视化需要足够的历史记录数据，建议至少每个用户有10条以上记录
2. **权限要求**：只有管理员可以查看可视化分析
3. **性能考虑**：生成图表需要一定时间，前端会显示加载提示
4. **字体支持**：后端需要支持中文字体，否则图表中文可能显示为方块
