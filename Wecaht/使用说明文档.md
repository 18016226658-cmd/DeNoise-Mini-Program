## 系统简介

大整数分解系统是一个基于微信小程序和 Python 后端的在线大整数分解工具。系统支持最多 200 位整数的分解计算，采用 Pollard's Rho 算法和 Miller-Rabin 素性测试，提供高效、准确的大整数分解服务。

### 主要特性

- ✅ **大整数分解**：支持最多 200 位整数的分解
- ✅ **用户管理**：完整的用户注册、登录、权限管理功能
- ✅ **历史记录**：自动保存分解历史，支持查询和统计
- ✅ **可视化分析**：提供多种数据可视化图表（管理员功能）
- ✅ **权限分级**：普通用户、VIP、SVIP、管理员四级权限体系

## 快速开始

### 1. 环境准备

#### 后端环境

- Python 3.8 或更高版本
- MySQL 5.7 或更高版本
- pip 包管理工具

#### 前端环境

- 微信开发者工具（最新版本）
- 微信账号（用于登录开发者工具）

### 2. 后端部署

#### 步骤 1：安装依赖

```bash
cd backend
pip install -r requirements.txt
```

#### 步骤 2：创建数据库

在 MySQL 中执行以下命令：

```sql
CREATE DATABASE xqq CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 步骤 3：初始化数据库

```bash
python init_db.py
```

执行成功后，系统会自动创建数据表并初始化管理员账户：
- 用户名：`xqq`
- 密码：`123456`

#### 步骤 4：启动后端服务

```bash
python app.py
```

后端服务默认运行在 `http://127.0.0.1:5000`

**注意**：如果需要在局域网中访问（真机调试），请确保防火墙允许 5000 端口的访问。

### 3. 前端部署

#### 步骤 1：配置后端地址

打开 `utils/common.js` 文件，修改 `BASE_URL`：

```javascript
// 开发阶段（本机模拟器）
const BASE_URL = 'http://127.0.0.1:5000';

// 真机/局域网调试（请改为你电脑的局域网 IP）
// const BASE_URL = 'http://10.60.32.34:5000';
```

**如何获取局域网 IP**：
- Windows：在命令行执行 `ipconfig`，查看 IPv4 地址
- Mac/Linux：在终端执行 `ifconfig`，查看 inet 地址

#### 步骤 2：导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目目录（`Wecaht` 文件夹）
4. AppID 选择"测试号"或使用自己的 AppID

#### 步骤 3：编译运行

点击"编译"按钮，在模拟器中查看效果。

## 功能使用指南

### 1. 用户注册与登录

#### 1.1 用户注册

1. 打开小程序，进入登录页面
2. 点击"注册"标签
3. 填写注册信息：
   - **用户名**：3-20 个字符，只能包含字母、数字、下划线
   - **密码**：至少 6 位
   - **确认密码**：必须与密码一致
   - **性别**：选择性别
   - **出生日期**：选择出生年月日
   - **职业**：输入职业信息
4. 点击"注册"按钮
5. 注册成功后自动登录

**注意**：新用户默认为"普通用户"，最大分解位数为 50 位。如需提升权限，请联系管理员。

#### 1.2 用户登录

1. 在登录页面输入用户名和密码
2. （可选）勾选"记住密码"，下次登录时自动填充
3. 点击"登录"按钮
4. 登录成功后进入首页

#### 1.3 默认管理员账户

- **用户名**：`xqq`
- **密码**：`123456`

管理员可以查看所有用户、修改用户等级、查看可视化分析等。

### 2. 大整数分解

#### 2.1 输入数字

1. 进入"分解"页面
2. 在输入框中输入要分解的数字（只允许输入 0-9）
3. 系统会自动：
   - 过滤非数字字符
   - 检查前导零
   - 显示数字位数
   - 快速判断数字类型（素数/合数/未知）

#### 2.2 开始分解

1. 确认输入数字无误
2. 选择分解模式：
   - **标准模式**：优先完全分解，适合大多数情况
   - **快速模式**：更快给出部分分解结果，适合超大数字
3. 点击"开始分解"按钮
4. 等待计算完成

#### 2.3 查看结果

分解完成后，页面会显示：

- **原数**：输入的数字
- **数字类型**：素数、合数、非素非合、未知
- **分解程度**：完全分解、部分分解、不能分解
- **所有因子**：列出所有因子，标注是否为素数
- **分解式**：标准分解式（如：2² × 3 × 5）
- **计算耗时**：分解所用时间（秒）

#### 2.4 复制结果

点击"复制结果"按钮，可以将分解结果复制到剪贴板。

#### 2.5 保存到历史

分解完成后，结果会自动保存到历史记录。你也可以在历史页面查看所有记录。

### 3. 历史记录

#### 3.1 查看历史记录

1. 进入"历史"页面
2. 系统会显示你的所有分解历史记录
3. 每条记录包含：
   - 原数
   - 分解式
   - 计算耗时
   - 数字类型
   - 分解程度
   - 分解时间

#### 3.2 查看详情

点击某条历史记录，可以查看详细信息，包括所有因子列表。

#### 3.3 清空历史

点击"清空历史"按钮，可以删除所有历史记录。

**注意**：清空操作不可恢复，请谨慎操作。

#### 3.4 统计信息

历史页面顶部显示统计信息：
- **总记录数**：你的历史记录总数
- **完全分解数**：完全分解的记录数

### 4. 个人中心

#### 4.1 查看个人信息

在"我的"页面可以查看：
- 用户名
- 用户等级
- 最大分解位数
- 注册时间
- 最后登录时间
- 登录次数

#### 4.2 退出登录

点击"退出登录"按钮，退出当前账户。

### 5. 管理员功能

**注意**：以下功能仅管理员可用。

#### 5.1 用户管理

1. 进入"管理员"页面（在"我的"页面底部）
2. 查看所有用户列表
3. 按等级筛选用户：
   - 全部用户

## 常见问题

### Q1：为什么分解速度很慢？

**A**：分解速度取决于数字的大小和复杂度：
- 20 位数字：通常 3-5 秒
- 50 位数字：通常 20-30 秒
- 100 位数字：通常 50-120 秒
- 150 位以上：可能需要更长时间

**建议**：
- 对于超大数字，使用"快速模式"可以获得部分分解结果
- 保持网络连接稳定
- 确保后端服务正常运行

### Q2：提示"超过最大位数限制"怎么办？

**A**：不同用户等级有不同的最大分解位数限制：
- 普通用户：50 位
- VIP 用户：80 位
- SVIP 用户：120 位
- 管理员：200 位

如需提升权限，请联系管理员修改你的用户等级。

### Q3：真机调试时无法连接后端？

**A**：请检查以下几点：

1. **后端地址配置**：在 `utils/common.js` 中，将 `BASE_URL` 改为你电脑的局域网 IP（不是 `127.0.0.1`）
2. **网络连接**：确保手机和电脑在同一局域网
3. **防火墙设置**：确保防火墙允许 5000 端口的访问
4. **后端服务**：确保后端服务正在运行

### Q4：如何获取局域网 IP？

**Windows**：
1. 按 `Win + R`，输入 `cmd`，回车
2. 在命令行中输入 `ipconfig`
3. 查找"IPv4 地址"，例如：`192.168.1.100`

**Mac/Linux**：
1. 打开终端
2. 输入 `ifconfig`（Mac）或 `ip addr`（Linux）
3. 查找 `inet` 地址，例如：`192.168.1.100`

### Q5：历史记录丢失了？

**A**：历史记录存储在服务器数据库中，不会因为小程序卸载而丢失。如果看不到历史记录，请检查：
1. 是否登录了正确的账户
2. 网络连接是否正常
3. 后端服务是否正常运行

### Q6：忘记管理员密码怎么办？

**A**：可以通过以下方式重置：

1. **方法一**：直接修改数据库
   ```sql
   UPDATE users SET password = '123456' WHERE username = 'xqq';
   ```

2. **方法二**：删除管理员账户，重新运行 `python init_db.py` 初始化

### Q7：如何备份数据？

**A**：可以通过以下方式备份：

1. **备份数据库**：
   ```bash
   mysqldump -u root -p xqq > backup.sql
   ```

2. **恢复数据库**：
   ```bash
   mysql -u root -p xqq < backup.sql
   ```
