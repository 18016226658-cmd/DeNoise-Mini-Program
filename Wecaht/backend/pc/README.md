# 可视化图表生成说明

## 概述

本目录包含多个Python脚本，每个脚本生成一张可视化图表，保存到当前目录。

## 脚本列表

### 1. `01_分解时间偏好分析.py`
生成分解时间偏好分析图，包含：
- 24小时使用分布柱状图
- 时间段分类统计饼图

**输出**: `01_分解时间偏好分析.png`

### 2. `02_职业词云图.py`
生成职业分布词云图，包含：
- 职业词云图
- 职业使用统计柱状图

**输出**: `02_职业词云图.png`

**注意**: 需要安装wordcloud库
```bash
pip install wordcloud
```

### 3. `03_用户等级分布分析.py`
生成用户等级分布分析图，包含：
- 用户数量分布饼图
- 各等级历史记录数柱状图
- 各等级平均分解耗时折线图
- 用户数与记录数对比图

**输出**: `03_用户等级分布分析.png`

### 4. `04_数字位数分布分析.py`
生成数字位数分布分析图，包含：
- 位数分布直方图
- 位数范围分布饼图
- 位数与耗时关系散点图
- 各位数范围平均耗时柱状图

**输出**: `04_数字位数分布分析.png`

### 5. `05_生成所有图表.py`
一键生成所有图表的主脚本

## 使用方法

### 方法1：单独运行每个脚本

```bash
cd backend/pc
python 01_分解时间偏好分析.py
python 02_职业词云图.py
python 03_用户等级分布分析.py
python 04_数字位数分布分析.py
```

### 方法2：一键生成所有图表

```bash
cd backend/pc
python 05_生成所有图表.py
```

## 依赖要求

```bash
pip install matplotlib numpy wordcloud
```

## 注意事项

1. **数据要求**: 需要先运行数据生成脚本生成用户和历史记录数据
2. **字体支持**: 脚本已配置中文字体，如果显示乱码，请检查系统字体
3. **图片质量**: 所有图表以300 DPI保存，适合打印和展示

## 输出文件

所有生成的PNG图片保存在 `backend/pc/` 目录下，文件名格式为：
- `01_分解时间偏好分析.png`
- `02_职业词云图.png`
- `03_用户等级分布分析.png`
- `04_数字位数分布分析.png`
