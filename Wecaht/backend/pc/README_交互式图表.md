# 交互式可视化图表生成说明

## 概述

所有可视化图表已升级为**交互式图表**，使用 Plotly 生成，支持：
- 🔍 缩放和平移
- 📊 悬停查看详细数据
- 📥 下载为PNG/SVG/HTML
- 🔄 图例点击显示/隐藏数据系列
- 📱 响应式设计，适配不同屏幕

## 安装依赖

```bash
pip install plotly
```

如果之前已安装，确保版本 >= 5.0.0：
```bash
pip install --upgrade plotly
```

## 脚本列表

### 1. `01_分解时间偏好分析.py`
生成分解时间偏好分析交互式图表，包含：
- 24小时使用分布柱状图（交互式）
- 时间段分类统计饼图（交互式）

**输出**: `01_分解时间偏好分析.html`

### 2. `02_职业词云图.py`
生成职业分布可视化，包含：
- 职业使用统计柱状图（交互式）
- 职业词云图（PNG格式，单独保存）

**输出**: 
- `02_职业词云图.html`（交互式柱状图）
- `02_职业词云图_词云.png`（词云图）

**注意**: 需要安装wordcloud库
```bash
pip install wordcloud
```

### 3. `03_用户等级分布分析.py`
生成用户等级分布分析交互式图表，包含：
- 用户数量分布饼图（交互式）
- 各等级历史记录数柱状图（交互式）
- 各等级平均分解耗时折线图（交互式）
- 用户数与记录数对比图（交互式）

**输出**: `03_用户等级分布分析.html`

### 4. `04_数字位数分布分析.py`
生成数字位数分布分析交互式图表，包含：
- 位数分布直方图（交互式）
- 位数范围分布饼图（交互式）
- 位数与耗时关系散点图（交互式）
- 各位数范围平均耗时柱状图（交互式）

**输出**: `04_数字位数分布分析.html`

### 5. `05_时间趋势与分解次数分析.py`
生成时间趋势与分解次数分析交互式图表，包含：
- 按年 / 月 / 日的使用次数折线图（可通过按钮切换）
- 不同分解程度的平均分解次数柱状图（交互式）
- 不同分解程度分解次数分布箱线图（交互式）

**输出**: `05_时间趋势与分解次数分析.html`

### 6. `05_生成所有图表.py`
一键生成所有交互式图表的主脚本

## 使用方法

### 方法1：一键生成所有图表

```bash
cd backend/pc
python 05_生成所有图表.py
```

### 方法2：单独运行每个脚本

```bash
cd backend/pc
python 01_分解时间偏好分析.py
python 02_职业词云图.py
python 03_用户等级分布分析.py
python 04_数字位数分布分析.py
python 05_时间趋势与分解次数分析.py
```

## 查看交互式图表

生成的HTML文件可以直接在浏览器中打开：

1. 双击HTML文件，或在浏览器中打开
2. 使用鼠标进行交互：
   - **缩放**: 鼠标滚轮或工具栏缩放按钮
   - **平移**: 点击并拖拽
   - **悬停**: 鼠标悬停在数据点上查看详细信息
   - **图例**: 点击图例项显示/隐藏对应数据系列
   - **下载**: 点击工具栏的相机图标下载为PNG

## 输出文件

所有生成的HTML文件保存在 `backend/pc/` 目录下：
- `01_分解时间偏好分析.html`
- `02_职业词云图.html`
- `02_职业词云图_词云.png`
- `03_用户等级分布分析.html`
- `04_数字位数分布分析.html`
- `05_时间趋势与分解次数分析.html`

## 交互式功能说明

### 工具栏功能
- 🔍 **缩放**: 放大/缩小图表
- 📐 **平移**: 移动图表视图
- 📷 **下载**: 下载为PNG/SVG/HTML格式
- 🔄 **重置**: 重置缩放和平移
- 📊 **自动缩放**: 自动调整视图范围

### 悬停提示
鼠标悬停在数据点上会显示：
- 数据点的详细数值
- 百分比（对于饼图）
- 其他相关统计信息

### 图例交互
- 点击图例项可以显示/隐藏对应的数据系列
- 双击图例项可以单独显示该系列

## 注意事项

1. **数据要求**: 需要先运行数据生成脚本生成用户和历史记录数据
2. **浏览器兼容性**: 推荐使用现代浏览器（Chrome、Firefox、Edge、Safari）
3. **中文显示**: 图表已配置中文字体支持
4. **文件大小**: HTML文件可能较大（包含所有交互式代码），适合本地查看和分享

## 从静态图表迁移

如果您之前使用的是静态PNG图表，现在已全部升级为交互式HTML图表：
- ✅ 更好的用户体验
- ✅ 更丰富的数据展示
- ✅ 支持导出为多种格式
- ✅ 无需额外软件，浏览器即可查看

## 技术说明

- **图表库**: Plotly (Python)
- **输出格式**: HTML (包含完整的交互式JavaScript代码)
- **字体支持**: SimHei, Microsoft YaHei, Arial
- **颜色方案**: Plotly内置颜色方案（Viridis, Plasma, Set3等）
