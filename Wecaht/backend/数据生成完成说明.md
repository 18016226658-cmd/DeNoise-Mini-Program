### 3. 创建真实数据生成脚本

#### 3.1 `generate_real_users.py`
生成500个真实用户：
- 300个普通用户（最大分解50位）
- 150个VIP用户（最大分解80位）
- 49个SVIP用户（最大分解120位）
- 1个管理员（xqq，最大分解200位）

每个用户包含：
- 随机性别、职业、出生日期
- 随机注册时间（过去1年内）
- 随机登录次数（1-100次）

#### 3.2 `generate_real_histories.py`
为每个用户生成10-20条历史记录：
- 使用真实的Pollard's Rho算法进行分解
- 根据用户等级限制生成相应位数的数字
- 生成真实的分解结果、耗时、数字类型等信息
- 随机生成时间（过去90天内）

#### 3.3 `generate_all_real_data.py`
一键生成所有数据的主脚本

## 📋 使用方法

### 快速开始

```bash
cd backend
python generate_all_real_data.py
```

### 分步执行

```bash
# 步骤1：生成500个用户
python generate_real_users.py

# 步骤2：为每个用户生成10-20条历史记录
python generate_real_histories.py
```

## 📊 生成的数据量

- **用户数量**：500个（不包括管理员xqq）
- **历史记录数量**：约5000-10000条（每个用户10-20条）
- **预计生成时间**：10-30分钟（取决于数字大小和计算复杂度）

## ⚙️ 数据库配置

脚本使用以下配置（在 `config.py` 中）：
- 数据库名：`xqq`
- 用户名：`root`
- 密码：`123456`
- 主机：`localhost`
- 端口：`3306`

## 🔍 数据特点

1. **真实性**：使用真实的分解算法，不是模拟数据
2. **符合身份**：每个用户的分解位数限制符合其等级
3. **时间分布**：记录时间分布在过去90天内
4. **多样性**：包含不同职业、性别、年龄段的用户

## 📝 注意事项

1. **执行时间**：生成历史记录需要真实计算，可能需要较长时间
2. **数据覆盖**：如果已有用户或记录，脚本会跳过或继续添加
3. **内存使用**：采用批量提交策略（每100条提交一次）
4. **错误处理**：单条记录失败不会中断整个流程

## 🧪 验证数据
