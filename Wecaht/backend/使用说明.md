# 大整数分解系统 - Python 后端使用说明

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 创建数据库

在 MySQL 中执行：

```sql
CREATE DATABASE xqq CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. 初始化数据库表

```bash
python init_db.py
```

这将创建所有数据库表并初始化管理员账户（用户名：xqq，密码：123456）

### 4. 启动服务

**Windows:**
```bash
run.bat
```

**Linux/Mac:**
```bash
chmod +x run.sh
./run.sh
```

或者直接运行：
```bash
python app.py
```

服务将在 `http://localhost:5000` 启动

## API 使用示例

### 1. 用户登录

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "xqq",
    "password": "123456"
  }'
```

响应：
```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "user": {...},
    "token": "xqq"
  }
}
```

### 2. 用户注册

```bash
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "123456",
    "password_confirm": "123456",
    "gender": "male",
    "gender_name": "男",
    "birth_year": 2000,
    "birth_month": 1,
    "birth_day": 1,
    "job": "学生"
  }'
```

### 3. 分解大整数

```bash
curl -X POST http://localhost:5000/api/factorize/factorize \
  -H "Content-Type: application/json" \
  -H "Authorization: xqq" \
  -d '{
    "number": "123456789",
    "mode": "standard"
  }'
```

### 4. 获取历史记录

```bash
curl -X GET "http://localhost:5000/api/history/list?page=1&per_page=20" \
  -H "Authorization: xqq"
```

### 5. 可视化分析（需要管理员权限）

**不同职业的使用时间分布：**
```bash
curl -X GET http://localhost:5000/api/analysis/job-usage-time \
  -H "Authorization: xqq"
```

**用户偏好分析：**
```bash
curl -X GET http://localhost:5000/api/analysis/user-preferences \
  -H "Authorization: xqq"
```

**使用统计信息：**
```bash
curl -X GET http://localhost:5000/api/analysis/usage-statistics \
  -H "Authorization: xqq"
```

## 可视化分析功能说明

### 1. 职业使用时间分布

分析不同职业在一天24小时内的使用情况，生成折线图，显示：
- 各职业在不同时间段的使用频率
- 哪些职业在哪些时间段更活跃

### 2. 用户偏好分析

生成6个子图，包括：
- **各职业使用频率**：饼图显示不同职业的使用占比
- **性别使用频率**：柱状图显示男女用户的使用情况
- **年龄段使用频率**：柱状图显示不同年龄段的使用情况
- **数字位数分布**：柱状图显示用户偏好分解的数字位数范围
- **数字类型分布**：饼图显示素数、合数等类型的分布
- **每日使用趋势**：折线图显示系统使用量的时间趋势

### 3. 使用统计信息

返回系统整体统计数据：
- 总用户数
- 总使用次数
- 今日/本周/本月使用次数
- 平均分解耗时
- 完全分解成功率

## 数据库配置

默认配置（可在 `config.py` 中修改）：
- 主机：localhost
- 端口：3306
- 用户名：root
- 密码：123456
- 数据库名：xqq

可以通过环境变量覆盖：
```bash
export MYSQL_HOST=localhost
export MYSQL_PORT=3306
export MYSQL_USER=root
export MYSQL_PASSWORD=123456
export MYSQL_DATABASE=xqq
```

## 注意事项

1. **生产环境安全**：
   - 修改默认管理员密码
   - 使用 JWT 进行身份认证
   - 密码使用哈希存储（如 bcrypt）
   - 启用 HTTPS

2. **性能优化**：
   - 大数字分解可能需要较长时间
   - 建议使用异步任务队列（如 Celery）处理长时间任务
   - 定期清理旧的历史记录

3. **数据库维护**：
   - 定期备份数据库
   - 监控数据库性能
   - 适当添加索引优化查询

## 常见问题

**Q: 连接数据库失败？**
A: 检查 MySQL 服务是否启动，数据库是否创建，用户名密码是否正确。

**Q: 导入模块失败？**
A: 确保已安装所有依赖：`pip install -r requirements.txt`

**Q: 可视化图表中文显示乱码？**
A: 确保系统已安装中文字体（SimHei、Microsoft YaHei 等）

**Q: 分解大数字很慢？**
A: 这是正常的，大数字分解是计算密集型任务，可能需要几分钟甚至更长时间。
