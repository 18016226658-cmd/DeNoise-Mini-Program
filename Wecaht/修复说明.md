# 用户等级和分解位数显示问题修复说明

## 问题描述

1. 注册成功后，管理员修改用户等级后，应该将等级数据保存（修改）到数据库中的有关记录
2. 用户登录后，需要将用户的身份（等级）获取到，设置为"全局变量"，所有页面都能"看到"
3. 分解位数应该根据这个变量设置为"正确"的分解位数
4. 目前所有用户都是分解五十位，需要根据用户等级动态设置
5. 需要创建SQL代码存入MySQL，Python后端连接MySQL进行可视化操作

## 修复内容

### 1. 修复分解页面显示问题

**文件**: `pages/splitter/splitter.js`

**修改内容**:
- 在 `onLoad()` 和 `onShow()` 方法中，先从全局变量快速获取用户信息，避免延迟
- 确保 `maxDigits` 从全局变量正确读取并显示

**关键代码**:
```javascript
onLoad() {
  this.checkLogin();
  // 先从全局变量快速获取用户信息（避免延迟）
  const userInfo = app.getUserInfo();
  if (userInfo) {
    this.setData({
      maxDigits: userInfo.max_digits || userInfo.maxDigits || 50
    });
  }
  // 然后从后端获取最新信息（确保等级改变后能及时更新）
  this.loadUserInfo();
  // 监控内存
  this.startMemoryMonitor();
}
```

### 2. 修复全局变量更新问题

**文件**: `app.js`

**修改内容**:
- 修改 `updateUserInfo()` 方法，确保字段名兼容性
- 同时设置 `max_digits` 和 `maxDigits`，以及 `level_name` 和 `levelName`
- 确保所有页面都能正确读取用户等级和最大分解位数

**关键代码**:
```javascript
updateUserInfo(userInfo) {
  try {
    // 统一字段名，确保兼容性（后端返回max_digits，前端可能使用maxDigits）
    const normalizedUserInfo = {
      ...userInfo,
      // 确保同时有max_digits和maxDigits
      max_digits: userInfo.max_digits || userInfo.maxDigits || 50,
      maxDigits: userInfo.max_digits || userInfo.maxDigits || 50,
      // 确保同时有level_name和levelName
      level_name: userInfo.level_name || userInfo.levelName || '普通用户',
      levelName: userInfo.level_name || userInfo.levelName || '普通用户'
    };
    
    // 更新全局变量（所有页面都能访问）
    this.globalData.userInfo = normalizedUserInfo;
    this.globalData.isLoggedIn = true;
    
    // 更新本地存储
    safeSetStorage('currentUser', normalizedUserInfo);
    
    // ... 其他更新逻辑
  } catch (e) {
    console.error('更新用户信息失败:', e);
  }
}
```

## 注意事项

1. **字段名兼容性**: 后端返回 `max_digits`（下划线格式），前端可能使用 `maxDigits`（驼峰格式）。已通过 `updateUserInfo()` 方法统一处理。

2. **全局变量更新时机**:
   - 登录时：自动更新
   - 管理员修改等级时：如果被修改的是当前登录用户，自动更新
   - 页面显示时：从全局变量读取，如果不存在则从后端获取

3. **数据库连接**: 确保 MySQL 数据库已创建并配置正确（参考 `backend/config.py`）

4. **可视化功能**: 需要安装 matplotlib 库，已在 `requirements.txt` 中声明
