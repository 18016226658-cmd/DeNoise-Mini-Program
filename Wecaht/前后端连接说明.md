# 微信小程序与 Python 后端连接详解

## 一、连接方式概述

微信小程序通过 **HTTP/JSON** 方式与 Python Flask 后端通信：

```
┌─────────────────┐         HTTP/JSON          ┌─────────────────┐
│                 │ ◄────────────────────────► │                 │
│  微信小程序前端   │    wx.request()            │  Python Flask    │
│  (JavaScript)   │                            │      后端        │
│                 │                            │                 │
└─────────────────┘                            └─────────────────┘
```

### 3. 统一请求封装函数

**文件**：`utils/common.js` 第 24-77 行

```javascript
function requestApi(options = {}) {
  const {
    url,              // API 路径（不含 BASE_URL）
    method = 'GET',   // 请求方法（GET/POST/PUT/DELETE）
    data = {},        // 请求数据
    success,          // 成功回调
    fail,             // 失败回调
    complete,         // 完成回调
    showLoading = true // 是否显示加载提示
  } = options;

  if (showLoading) {
    wx.showLoading({ title: '请求中...', mask: true });
  }

  // 使用微信小程序的 wx.request 发起 HTTP 请求
  wx.request({
    url: BASE_URL + url,  // 完整 URL = 后端地址 + API 路径
    method,               // GET/POST/PUT/DELETE
    data,                 // 请求体数据（JSON 格式）
    header: {
      'Content-Type': 'application/json',
      'Authorization': getAuthToken()  // 自动添加认证 Token
    },
    success: (res) => {
      if (showLoading) {
        wx.hideLoading();
      }

      // 处理 401 未授权（自动跳转登录）
      if (res.statusCode === 401) {
        wx.removeStorageSync('currentUser');
        wx.reLaunch({ url: '/pages/login/login' });
        return;
      }

      if (typeof success === 'function') {
        success(res);
      }
    },
    fail: (err) => {
      if (showLoading) {
        wx.hideLoading();
      }
      showError('网络请求失败，请检查网络或稍后重试');
      if (typeof fail === 'function') {
        fail(err);
      }
    },
    complete: () => {
      if (typeof complete === 'function') {
        complete();
      }
    }
  });
}
```

**关键点**：
1. **自动拼接 URL**：`BASE_URL + url`
2. **自动添加认证头**：`Authorization: 用户名`
3. **统一错误处理**：401 自动跳转登录
4. **统一加载提示**：自动显示/隐藏 loading

### 4. 认证 Token 获取

**文件**：`utils/common.js` 第 11-18 行

```javascript
function getAuthToken() {
  try {
    const currentUser = wx.getStorageSync('currentUser');
    return currentUser && currentUser.username ? currentUser.username : '';
  } catch (e) {
    return '';
  }
}
```

**说明**：
- 当前实现使用**用户名**作为 Token（简单方式）
- 生产环境应使用 JWT（JSON Web Token）
- Token 存储在请求头的 `Authorization` 字段中

## 三、前端调用示例

### 示例 1：用户登录

**文件**：`pages/login/login.js`

```javascript
// 引入 requestApi
const { requestApi, showError, showSuccess } = require('../../utils/common.js');

// 处理登录
handleLogin() {
  const { loginUsername, loginPassword } = this.data;

  if (!loginUsername || !loginPassword) {
    wx.showToast({ title: '请输入用户名和密码', icon: 'none' });
    return;
  }

  // 调用后端登录接口
  requestApi({
    url: '/api/auth/login',        // API 路径
    method: 'POST',                 // 请求方法
    data: {                         // 请求数据
      username: loginUsername,
      password: loginPassword
    },
    success: (res) => {
      const data = res.data || {};
      if (data.success) {
        const user = data.data.user;
        const token = data.data.token;

        // 保存用户信息到本地
        wx.setStorageSync('currentUser', user);
        
        // 更新全局状态
        app.globalData.userInfo = user;
        app.globalData.isLoggedIn = true;

        showSuccess('登录成功');
        setTimeout(() => {
          wx.switchTab({ url: '/pages/home/home' });
        }, 1500);
      } else {
        showError(data.message || '登录失败');
      }
    },
    fail: (err) => {
      console.error('登录请求失败:', err);
      // requestApi 内部已处理错误提示
    }
  });
}
```

## 四、后端实现（Python Flask）

### 1. 后端入口文件

**文件**：`backend/app.py`

```python
from flask import Flask
from flask_cors import CORS
from config import Config
from models import db, User
from api.auth import auth_bp
from api.factorize import factorize_bp
from api.history import history_bp
from api.admin import admin_bp
from api.analysis import analysis_bp

def create_app():
    """创建并配置 Flask 应用"""
    app = Flask(__name__)
    app.config.from_object(Config)
    
    # 初始化数据库
    db.init_app(app)
    
    # 启用 CORS（跨域资源共享）- 允许小程序访问
    CORS(app, resources={r"/api/*": {"origins": "*"}})
    
    # 注册蓝图（Blueprint）- 组织 API 路由
    app.register_blueprint(auth_bp, url_prefix='/api/auth')
    app.register_blueprint(factorize_bp, url_prefix='/api/factorize')
    app.register_blueprint(history_bp, url_prefix='/api/history')
    app.register_blueprint(admin_bp, url_prefix='/api/admin')
    app.register_blueprint(analysis_bp, url_prefix='/api/analysis')
    
    # 创建数据库表
    with app.app_context():
        db.create_all()
        init_admin_user()
    
    return app

if __name__ == '__main__':
    app = create_app()
    app.run(host='0.0.0.0', port=5000, debug=True)
```

**关键点**：
1. **CORS 配置**：`CORS(app, resources={r"/api/*": {"origins": "*"}})` - 允许跨域请求
2. **蓝图注册**：使用 `url_prefix` 定义 API 前缀
3. **监听地址**：`host='0.0.0.0'` - 允许局域网访问

#### 示例 1：登录接口

**文件**：`backend/api/auth.py` 第 29-74 行

```python
from flask import Blueprint, request, jsonify
from models import db, User
from datetime import datetime

auth_bp = Blueprint('auth', __name__)

@auth_bp.route('/login', methods=['POST'])
def login():
    """用户登录接口"""
    try:
        # 1. 获取请求数据
        data = request.get_json()
        username = data.get('username', '').strip()
        password = data.get('password', '').strip()
        
        # 2. 验证输入
        if not username or not password:
            return jsonify({
                'success': False,
                'message': '请输入用户名和密码'
            }), 400
        
        # 3. 查询用户
        user = User.query.filter_by(username=username).first()
        
        if not user:
            return jsonify({
                'success': False,
                'message': '用户不存在'
            }), 404
        
        # 4. 验证密码
        if user.password != password:
            return jsonify({
                'success': False,
                'message': '密码错误'
            }), 401
        
        # 5. 更新登录信息
        user.last_login_time = datetime.now()
        user.login_count = (user.login_count or 0) + 1
        db.session.commit()
        
        # 6. 返回结果
        return jsonify({
            'success': True,
            'message': '登录成功',
            'data': {
                'user': user.to_dict(),
                'token': username  # 返回 Token（用户名）
            }
        })
    except Exception as e:
        return jsonify({
            'success': False,
            'message': f'登录失败: {str(e)}'
        }), 500
```

### 4. 登录验证装饰器

**文件**：`backend/api/auth.py` 第 11-27 行

```python
def login_required(f):
    """登录验证装饰器"""
    @wraps(f)
    def decorated_function(*args, **kwargs):
        # 1. 从请求头获取 Token
        token = request.headers.get('Authorization')
        if not token:
            return jsonify({'success': False, 'message': '未登录'}), 401
        
        # 2. 根据 Token（用户名）查询用户
        user = User.query.filter_by(username=token).first()
        if not user:
            return jsonify({'success': False, 'message': '无效的 token'}), 401
        
        # 3. 将用户对象附加到 request，供后续使用
        request.current_user = user
        return f(*args, **kwargs)
    return decorated_function
```

**使用方式**：
```python
@factorize_bp.route('/factorize', methods=['POST'])
@login_required  # 使用装饰器，自动验证登录
def factorize_number():
    user = request.current_user  # 装饰器已注入用户对象
    # ...
```

## 八、总结

### 连接流程

1. **前端**：使用 `requestApi()` 函数发起 HTTP 请求
2. **请求**：通过 `wx.request()` 发送到后端
3. **后端**：Flask 接收请求，处理业务逻辑
4. **响应**：返回 JSON 格式数据
5. **前端**：在 `success` 回调中处理响应数据

### 关键文件

**前端**：
- `utils/common.js` - 请求封装
- `pages/*/**.js` - 页面调用

**后端**：
- `backend/app.py` - Flask 应用入口
- `backend/api/*.py` - API 接口实现
- `backend/config.py` - 配置文件

### 数据格式

- **请求**：JSON 格式，通过 `data` 参数传递
- **响应**：JSON 格式，统一结构：
  ```json
  {
    "success": true/false,
    "message": "提示信息",
    "data": { ... }
  }
  ```
